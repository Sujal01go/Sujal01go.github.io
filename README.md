## 🚀 Quick Start / Local Preview

The site is served locally on port 3000:

```bash
# Start HTTP server
python -m http.server 3000

# Open in browser
http://localhost:3000
```

---

## 🌐 Deploying to GitHub Pages

To publish live to GitHub Pages:
```powershell
git remote add origin https://github.com/Sujal01go/portfolio.git
git branch -M main
git push -u origin main
```
In your GitHub repository settings under **Pages**, select branch `main` / `root`. Your portfolio will be live at:
`https://sujal01go.github.io/portfolio/`
